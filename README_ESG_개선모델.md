# ESG 평가모델: 검색·근거 검증 개선판

원본 `esg_rule_engine.py`를 그대로 보존하고, `esg_rule_engine_improved.py`를 별도 실행합니다. 이 버전은 Rule Book의 채점 기준을 바꾸지 않고 **근거 검색과 검증 절차**를 보완합니다. 실제 삼성SDI 보고서 4개를 사용한 정확도 개선 여부는 아직 검증되지 않았습니다.

## 주요 변경

1. `--enhanced-search`: 윤리·신고자 보호·공급망·환경 지표 관련 유의어 확장
2. 다양한 키워드가 포함된 페이지를 우선 검색하고 특정 보고서 후보가 독점하지 않도록 2차 검색
3. 하나의 페이지에서 키워드가 가장 많이 공존하는 최대 3,200자 구간을 LLM에 전달
4. LLM이 **미확인**으로 판단한 경우 더 넓은 후보로 한 번 재검색하고 재판정 (추가 API 비용 발생)
5. 판정 결과 `1/0/N/A`에 대한 인용문·문서명·페이지가 실제 입력 발췌문과 일치하는지 검사. 불일치 시 `미확인`으로 보수적으로 처리
6. 결과의 `검색차수` 열에 재검색 여부 기록

**주의:** 엄격한 문자 일치 방식의 인용문 검증 때문에 공백·줄바꿈·표 분할 차이만으로도 검증이 실패할 수 있습니다. 또한 PDF 텍스트가 잘못 추출되거나 스캔 이미지만 있는 경우에는 별도의 표 추출/OCR이 필요합니다. 검색 방식 개선은 모든 미확인을 해결하지 않습니다.

## 실행 방법

```bash
pip install pandas openpyxl pypdf openai
python esg_rule_engine_improved.py \
  --rulebook "룰북.xlsx" \
  --pdf-dir "input_docs/삼성SDI" \
  --company "삼성SDI" \
  --target-year 2025 \
  --review-mode llm \
  --model "gpt-4.1-mini" \
  --enhanced-search \
  --output "삼성SDI_검색개선_결과.xlsx"
```

기존 **미확인 항목만** 다시 평가하려면 다음 인자를 추가합니다.

```bash
--refine-unconfirmed "삼성SDI_4개보고서_평가결과.xlsx"
```

기존 1/0/N/A 항목은 유지되므로, 전체 정확도를 비교하려면 **원본 결과와 동일한 문서·동일한 룰북을 사용해서 전체 규칙을 재실행**하고, 사람 검증 정답셋과 비교해야 합니다. 단순히 근거확인률이 높아졌다는 이유만으로 정확도가 향상됐다고 볼 수 없습니다.

## 권장 비교 지표

- 검색 적중률: 검증된 근거 페이지가 후보 Top-K에 포함된 비율
- 판정 정확도: 전문가 판정과 LLM 최종판정 일치율 (1/0/N/A/미확인 모두 포함)
- 미확인 비율 및 잘못된 1점/0점 판정 비율
- 원문 인용 검증 통과율, 규칙당 토큰/비용 및 소요 호출 수

## 현 버전의 제한

- 의미검색 임베딩, BM25, 표 전용 파서, 페이지 앞뒤 연결, GRI 인덱스 검색은 **아직 구현되지 않았습니다**. 실제 평가결과에서 병목이 남을 경우 추가 권장합니다.
- 출처 성과연도 자동 감지는 표지 표현에 좌우되며, 문서 단위 연도 필터링이 과도하게 작동할 수 있습니다. `평가연도 불일치로 제외된 문서` 열을 검토하세요.
- 규칙의 연도 문구 일부만 실행 시 치환되므로 Rule Book의 기준연도 자체를 팀에서 확정해야 합니다.
- `--enhanced-search` 옵션 없이 실행하면 검색어 확장은 사용되지 않지만, 그 외 검색 점수 알고리즘과 인용문 검증은 원본과 다릅니다. 엄밀한 A/B 비교에는 원본 스크립트와 개선판을 각각 실행하세요.
- API 키는 `.env`나 운영체제 환경변수로 관리하고 결과 파일 및 코드와 함께 공유하지 마세요.
