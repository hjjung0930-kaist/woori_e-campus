# ESG Rule Engine v2.1 — v2 회귀 수정판

## 배경
삼성SDI의 동일한 111개 규칙에서 v1의 판정완료 68개가 v2에서는 15개로 감소했습니다. v2는 40개를 인용검증 실패로 돌렸고, 56개는 미확인이었습니다. 이번 버전은 **v1에서 효과를 보인 검색 로직을 기본으로 사용**하면서, 공백/줄바꿈 차이에 한정한 인용 대조 및 2차 검색 결과 덮어쓰기 오류를 수정합니다. 이 버전이 점수 정확도를 검증하거나 근거확인률을 향상시킨다는 보장은 없습니다.

## 적용한 변경
- 개선판(v1)의 키워드/유의어 검색과 후보 다양화 복원. v2의 BM25 점수 조합은 일단 제외.
- 원문 인용이 공백·줄바꿈·유니코드 표현만 다른 경우 동일한 것으로 검증. **내용·숫자가 달라지는 경우 여전히 미확인**.
- 2차 검색이 미확인일 때 앞선 결과를 무조건 덮어쓰지 않음.
- 0점의 인용문 원문 존재는 확인하지만 **실제 인정조건 미충족 여부는 별도의 사람 검토 필요** (`검증상태` 열). 기존 0점도 무조건 사실로 인정하면 안 됨.

## 권장 실행 (미확인 43개에 한하여 재검증)
```bash
/opt/anaconda3/envs/sumin/bin/python esg_rule_engine_v2_1.py \
  --rulebook "룰북.xlsx" \
  --pdf-dir "input_docs/삼성SDI" \
  --company "삼성SDI" \
  --target-year 2025 \
  --output "삼성SDI_4개보고서_평가결과_v2_1.xlsx" \
  --review-mode llm \
  --model "gpt-5.1" \
  --enhanced-search \
  --refine-unconfirmed "삼성SDI_4개보고서_평가결과_improved.xlsx"
```

`--refine-unconfirmed`은 v1의 기존 1/0/N/A 판정을 **재검증 없이 유지**합니다. 따라서 결과의 근거확인률은 기존 판정의 옳음을 증명하는 수치가 아닙니다. 기존 0점 검증이 목적이라면 원문을 수동 점검하거나 별도 실험으로 수행하세요. 같은 네 보고서와 룰북을 사용해야 비교가 가능합니다.

## 테스트 여부
Python 문법검사, 인용문의 공백/줄바꿈 대조 성공, 변경된 문장 거절 테스트 통과. 삼성SDI 4개 PDF 및 실제 GPT API로 전수 검증하지 않았으므로 새 결과의 정확도/확인률은 미확정입니다.
